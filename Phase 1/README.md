This is the code of the first phase HQ-PIDT. 
- **HybridTransformerBlock.py**: Our proposed Hybrid Quantum Fidelity-Based Multi-Head Self-Attention and corresponding Hybrid Quantum Causal Transformer Block.
- **model_powersys_ori.py**: Full structure of our proposed HQ-PIDT.
- **train_powersys_ori.py**: Training and inferencing of our proposed HQ-PIDT.
- **utils_ori.py**: Sampling function of our proposed HQ-PIDT.
- **240bus_HDT_V3.py**: Example main execution file of loading data, train and test HQ-PIDT.
